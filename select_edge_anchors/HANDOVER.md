# SVG → Illustrator アンカーポイント選択ツール（ハンドオーバー）

## プロジェクト概要

Pythonで生成したネットワークグラフのSVGをIllustratorで開き、JSXスクリプトで「ノード（円）の選択を起点に、対応するエッジ（線）のアンカーポイントを自動でダイレクト選択する」ツールを開発している。データビジュアライゼーションをPythonで生成し、Illustratorで仕上げる際の編集効率を上げるのが目的。

## 確立済みの要件

### SVG生成側

- レイヤー構造：
  - `label`（サブレイヤー：groupA, groupB, groupC）
  - `node`（サブレイヤー：groupA, groupB, groupC）
  - `edge`
- 各ノード（円）はSVGの`<circle>`、各エッジは`<line>`
- レイヤー認識のため `<g>` に `id`、`inkscape:label`、`inkscape:groupmode="layer"` を付与
- 各オブジェクトに固有の `id` を振る（`node_USA`, `edge_USA_China` など）

### JSX側

- ユーザーが任意のノード（個別の円、サブレイヤー、複数選択など）を選択した状態でスクリプトを実行
- 選択されたノードの中心座標と一致（許容誤差1.0pt）するアンカーポイントを、edgeレイヤーの線から検出
- 該当アンカーポイントをダイレクト選択状態にする
- 実行前のオブジェクト選択・ダイレクト選択は維持する
- 選択解除されたターゲットの円自体はアンカー選択の対象外（中心座標が一致してしまうため除外）

## 実装上の重要な知見

1. **Illustratorはアンカーポイント自体に固有IDを持たせられない** → 同座標に円を配置してハンドル代わりにする方式で解決
2. **SVGの `<circle>` は GroupItem として読み込まれる場合がある** → 選択オブジェクトを再帰展開して PathItem を取り出す処理が必要
3. **レイヤーロックがあるとアンカー操作でエラー（Error 8705 / Error 1200 MRAP）** → スクリプト冒頭で全レイヤーのロックを再帰的に解除する必要がある
4. **親レイヤーがロック中だと子レイヤーのロック解除でエラー** → ボトムアップ（子から先に）で処理し、try-catchでエラー耐性を持たせる
5. **typename = "PathItem" だけ見ると GroupItem 選択時に弾かれる** → CompoundPathItem / GroupItem も再帰展開する

## 動作確認済み環境

- Illustrator v29.8.1 (2025)

## 互換性目標

- Illustrator v27.x 以降
- 使用APIはCS時代からあるものに限定済み（PathPointSelection、geometricBounds、typename など）
- ES3互換の書き方（var、try-catch、再帰関数のみ。アロー関数、let/const、Array.prototype.indexOf等は未使用）
